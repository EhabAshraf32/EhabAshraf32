## 🚀 Featured Projects

**[Agenyx — Multi-Agent AI Orchestration Platform](https://github.com/EhabAshraf32/Agenyx-Multi-Agent-AI-Orchestration-Platform-)** <!-- TODO: confirm/replace with the real repo URL --> — A stateful, human-in-the-loop multi-agent workflow built with **LangGraph** and **LangChain**, coordinating Planner, Researcher, Human Reviewer, Writer, Critic, and Finalizer agents with controlled iterations and critic-driven revision loops. Integrates **MCP** and Tool Calling with calculator and Tavily web-search tools via an MCP client/adapter, with **LangSmith** tracing for workflow observability. Implements LangGraph interrupt/resume for human approve/reject decisions, exposed through **FastAPI** endpoints for starting, monitoring, approving, rejecting, and retrieving results.
`Python` · `LangGraph` · `LangChain` · `LangSmith` · `MCP` · `FastAPI` · `Tool Calling`

**[RAGForge — End-to-End RAG Knowledge Platform](https://github.com/EhabAshraf32/RAGForge-End-to-End-RAG-Knowledge-Platform)** — A modular **Retrieval-Augmented Generation (RAG)** system built with the **Factory Design Pattern**, with an end-to-end **LangChain/Hugging Face** pipeline for PDF ingestion, semantic chunking, embedding generation, and retrieval. Exposes asynchronous REST APIs (**FastAPI, Pydantic, Motor, Dependency Injection**) for document ingestion, querying, and chat, validated with **Postman**. Integrates **Qwen2.5-1.5B-Instruct, Qdrant, and MongoDB** with prompt engineering and conversation memory for grounded, source-aware responses, a **Streamlit UI** for upload/process/index/search/chat, and is **Dockerized** for reproducible deployment.
`Python` · `LangChain` · `Hugging Face Transformers` · `Qwen2.5` · `Qdrant` · `MongoDB` · `FastAPI` · `Streamlit` · `Docker`

**[Arabic Sentiment Swap – DialectSentEval 2026 Shared Task](https://github.com/EhabAshraf32/Arabic-Sentiment-Swap-using-mBART-LoRA-DialectSentEval-2026)** — A generative NLP project for **Subtask 2: Arabic Sentiment Swap**. Fine-tuned **mBART** using **PEFT (LoRA)** to generate sentiment-swapped Arabic text while preserving semantic meaning, writing style, dialect, and emojis, evaluated with **Sentiment Accuracy, BERTScore, BLEU, ROUGE, and Perplexity** on the **MA'AKS Extended** dataset.
`Python` · `Hugging Face Transformers` · `mBART` · `LoRA (PEFT)` · `Arabic NLP` · `Seq2Seq` · `Pandas` · `Scikit-learn`

**[CV–Job Match](https://github.com/EhabAshraf32/CV-Job-Match-Using-RAG-LLMs)** — An LLM-powered resume screening system using **RAG** to evaluate how well a candidate's CV matches a job description. Retrieves the most relevant resume sections with **FAISS** and **LaBSE embeddings**, then generates an explainable hiring assessment with a compatibility score, strengths, missing skills, and recommendations. The retrieval pipeline is evaluated with **Precision@K, Weighted Precision, Average Relevance Score, and nDCG**.
`Python` · `LangChain` · `RAG` · `FAISS` · `LaBSE` · `Hugging Face Transformers` · `LLMs` · `Prompt Engineering` · `PyMuPDF`
